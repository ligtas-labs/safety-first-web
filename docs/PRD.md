# Product requirements — web

## Goal

Let teachers assign and review work and let students inspect their confirmed progress.

## Planned user journey

A teacher opens a class, posts a reviewed activity and reads submitted attempts. A student can inspect deadlines, submission status and feedback.

## Acceptance demonstration

Test two classes, an empty class, a failed request and a revoked membership. Show pending, empty and error states separately. Verify navigation at phone and desktop widths.

Use synthetic accounts and record the build under test. Track delivery against the matching Linear stories.
